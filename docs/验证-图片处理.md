## 3. 接口与集成契约

模块：`H:\Public Opinion Search Capture System\src\opinion_capture\imaging.py`。

### compose_grid

```python
compose_grid(image_paths, output_path, columns=3, cell_width=360, gap=16,
             max_pixels=50_000_000, max_input_pixels=50_000_000) -> dict
```

- 清单按调用方提供的次序读取，绝不在模块内按文件名、完成时间或关键词重排；`columns=len(image_paths)` 即横排。
- 等比例缩小至列宽，小图不放大；每行采用本行最大高度，其余区域留白。高度取最近整数，存在至多半像素舍入。
- 输出包含 `path/width/height/pixels/format/inputs/columns/placements`；每个 placement 包含清单下标、原图尺寸、坐标及实际缩放尺寸。
- `gap` 同时用于四周和单元间；RGB 白底，透明输入铺白。超像素预算在分配画布前报 `ImagingError`，首版不自动拆分编号图。

### stitch_vertical

```python
stitch_vertical(image_paths, output_path, content_top=0, content_bottom=None,
                min_overlap=32, max_overlap=None, compare_width=48,
                max_error=1.5, min_margin=0.75, min_texture=8.0,
                max_pixels=50_000_000, max_input_pixels=50_000_000) -> dict
```

- 至少两张同宽、同缩放尺度、向下连续滚动的帧；按清单顺序拼接，不猜测顺序、横向移动、缩放或透视变换。
- `content_top` 为每帧内容区起点，`content_bottom` 为不含底边的终点；None 表示每张帧自己的底边。裁切作用于所有帧，结果仅保留内容区，首帧也不保留固定栏。固定搜索栏/悬浮栏应由调用方提供边界。
- 重叠搜索单位是原分辨率竖直像素：仅横向缩至最多 48 像素并转灰度，保留每一行，对所有合法重叠高度计算 MAE。保留竖直精度比双向粗缩略更简单，避免回映射的接缝偏移。
- 最佳 MAE 须不超过 1.5；次优与最佳之差须至少 0.75，包括相邻位移竞争者。不是校准概率，不应将 `status=accepted` 描述为平台连续性证明。
- 重叠区域分三段，每段须满足灰度标准差至少 8、相邻行平均差至少 1，并在原分辨率 RGB 下再次校验 MAE。防止仅灰度相似、空白或单处封面造成轻率匹配。
- 重复/近似静止帧、重复纹理歧义、空白、低纹理和超阈值误差抛 `OverlapError`，不回退到零重叠硬拼。所有对齐通过后才写入 PNG。
- 返回 `overlaps`，逐对记录帧下标、重叠高度、最佳/次优误差和 margin；该数据是图像匹配诊断，不是平台条目数。

### 文件与资源边界

- 输入只读；输出必须为新 `.png` 路径，原路径、已有派生图、指向已有原图的路径别名/硬链接都会报 `FileExistsError`。
- 输出以 `xb` 独占创建，避免检查后并发覆盖；保存后重新打开执行 PNG `verify()`。写入异常清理本次不完整文件，不清理既有文件。
- 每张输入文件头检查像素预算；只支持单帧图像，截图按存储像素方向处理，未实现 EXIF 自动旋转/色彩配置迁移。
- `max_pixels` 是输出画布像素上限，**不是进程内存硬限制**；还存在原图解码、缩放和对齐临时内存。匹配逐帧保留一对内容图，不一次保存所有解码帧，但穷举重叠对高帧尺寸仍有成本。
- 调用方应使用采集结束后的稳定原始文件，并负责批次/平台/端/类别/配置分组、关键词清单冻结、缺失项标识、历史版本命名。模块不读业务数据库，也不做这些判定。
