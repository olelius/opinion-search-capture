## 客户使用

1. 关闭程序（含托盘），替换更新包中的两个EXE，保留原来的_internal、.local及图片目录。新客户需取得完整OpinionCapture-Portable目录。
2. APP：先启动MuMu，再点“刷新设备”。自动发现失败可“选择ADB文件”选一次本机adb.exe，无需全局PATH。
3. WEB后台运行：选择“独立网页会话”，勾选“后台无头采集（登录仍打开窗口）”。首次点“打开网页登录”正常登录；已经登录会自动确认，显示“平台登录已确认；浏览器会话已保存”，随后窗口关闭。
4. 无头采集复用同一专属会话，不重新登录；登录过期/验证码仍需要正常处理。复用已有Chrome模式保持可用，但无头选项不改变用户已经打开的浏览器。

日常Chrome里的登录不会自动搬入程序专属会话；首次使用无头模式需在程序打开的专属窗口正常登录一次。
5. 登录会话与计划配置分开保存：关键词、目录、时段等表单修改后点“保存配置”。没有最终图片的任务现在明确失败；有图片但完整性未证实显示“未完整验收”，不是部分成功。
6. APP正常滚动目标为有效内容区80%，末段按TOP N缩短；真实位移由源帧验证，不将手势距离冒充画面位移。任务中可见连接、加载、截图、验证阶段及耗时。
